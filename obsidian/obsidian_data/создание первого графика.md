```python
from matplotlib import pyplot as plt 
import numpy as np 

fig, ax = plt.subplots(figsize=(10, 10))
ax.plot([1,2, 3, 4], [1, 4, 9, 16])
ax.set_title("**2")
plt.show()
```

- `plt.subplots(figsize=(8, 5))` — создаёт фигуру размером 8x5 дюймов и возвращает кортеж (fig, ax). Даже если тебе нужен всего один график, лучше использовать именно subplots(), а не plt.figure() — так у тебя сразу есть объект ax, с которым удобно работать.
- `ax.plot(x, y)` — метод объекта Axes, который рисует линию по координатам x и y.
- `ax.set_title(...)` — задаёт заголовок именно этому Axes (а не всей фигуре).
- `plt.show()` — отображает график. В Jupyter Notebook часто не обязателен, но в обычных скриптах — нужен.
