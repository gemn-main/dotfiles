## 2. Scikit-learn

Главная библиотека для всего, что не нейросети. Используется в каждой задаче.

### Метрики
- `f1_score(average='macro')` — macro F1 для классификации
- `mean_squared_error(squared=False)` — RMSE для регрессии
- `mean_absolute_error` — MAE для регрессии
- `ndcg_score` — NDCG для ранжирования

### Валидация
- `train_test_split(stratify=y)` — разделение с сохранением пропорций классов
- `StratifiedKFold` — кросс-валидация для классификации
- `cross_val_score` — быстро оценить модель на CV
- `GridSearchCV` — перебор гиперпараметров

### Предобработка
- `StandardScaler` — масштабирование числовых признаков
- `LabelEncoder` — кодирование категорий в числа (для одной колонки)
- `OneHotEncoder` — кодирование категорий через бинарные колонки
- `SimpleImputer` — заполнение пропусков (медиана, среднее)
- `Pipeline` — объединить предобработку и модель в один объект

### Базовые модели (для быстрого baseline)
- `RandomForestClassifier` / `RandomForestRegressor` — хороший старт перед бустингом
- Параметр `class_weight='balanced'` — автоматически борется с дисбалансом классов

### Текст
- `TfidfVectorizer` — превращает текст в числовые признаки

## 4. Классический ML (табличные данные)

Нужен для задач регрессии и классификации по числовым признакам (звёзды, книги и т.д.).

### Градиентный бустинг
- **CatBoost** — работает с категориальными признаками без ручного кодирования, лучший выбор для старта
- **LightGBM** — быстрее, подходит для больших данных; есть режим ranker для ранжирования
- Гиперпараметры: learning rate, глубина дерева, число итераций, регуляризация

### Предобработка данных
- Заполнение пропусков — медиана, среднее, KNN-imputer
- Кодирование категорий — LabelEncoder, OneHotEncoder
- Масштабирование — StandardScaler (важно для нейросетей, не обязательно для бустинга)
- Feature engineering — создание новых признаков из существующих

### Валидация
- **Кросс-валидация (StratifiedKFold)** — честная оценка модели
- **Temporal split** — при данных с временем нельзя использовать будущее для обучения; утечка данных (data leakage) — самая частая ошибка
- Подбор гиперпараметров — GridSearchCV или Optuna

### Метрики регрессии
- **RMSE** — среднеквадратичная ошибка, штрафует за большие ошибки сильнее
- **MAE** — средняя абсолютная ошибка, устойчива к выбросам

## 4. Классификация и метрики классификации

- **Macro F1 score** — главная метрика НТО для классификации; усредняет F1 по каждому классу, поэтому штрафует за плохие предсказания на редких классах
- **Несбалансированные классы** — редкий класс (экзопланеты, тигр) требует особого внимания:
  - `class_weight='balanced'` в параметрах модели
  - SMOTE — синтетическая генерация примеров редкого класса (библиотека imbalanced-learn)
  - Stratified split при делении на train/val
- **Precision, Recall, F1** — понимать, как считаются и чем отличаются

## 5. EDA — разведочный анализ данных

Делается перед обучением любой модели.

- Распределения признаков — гистограммы, box plot
- Корреляции — тепловая карта, выявление лишних и важных признаков
- Анализ дисбаланса классов — увидеть до обучения, сколько примеров в каждом классе
- Выбросы — найти и решить, что с ними делать
- Feature importance — после обучения смотреть, какие признаки важны для модели

## 6. Компьютерное зрение

Нужно для задач с изображениями (фотоловушки и подобные).

### PyTorch
- Тензоры — создание, операции, перенос на GPU (`.cuda()`)
- Dataset и DataLoader — как загружать изображения батчами
- Цикл обучения — forward pass, loss, backward, `optimizer.step()`
- Сохранение и загрузка весов — `torch.save` / `torch.load`
- torchvision — готовые архитектуры и трансформации

### Transfer learning
- Берёшь предобученную модель (ResNet, EfficientNet) и дообучаешь под свои классы
- Заморозка слоёв — обучать только голову или всю сеть

### Аугментации
- Случайные обрезки, повороты, изменение яркости и контраста
- Библиотека albumentations — гибче и быстрее torchvision.transforms

### Детекция объектов
- **YOLO (YOLOv8)** через библиотеку ultralytics — основной инструмент
- Bounding box — формат (cx, cy, w, h) нормализованный от 0 до 1
- **IoU** (Intersection over Union) — мера совпадения двух прямоугольников
- **mAP 0.5–0.95** — метрика качества детекции
- NMS (Non-Maximum Suppression) — убирает дублирующие боксы

## 7. Рекомендательные системы

Нужно для задач с историей взаимодействий пользователей (книги, фильмы и т.д.).

### Базовые идеи
- **Коллаборативная фильтрация** — рекомендуем на основе схожих пользователей или объектов
- **Content-based filtering** — рекомендуем по свойствам самого объекта
- User-Item матрица — таблица «пользователь × объект», значения — оценки или факт взаимодействия
- «Тёплые» пользователи — те, у кого есть история; «холодные» — новые

### Feature engineering для рекомендаций
- Агрегаты по пользователю — средняя оценка, количество взаимодействий, любимый жанр
- Агрегаты по объекту — средняя оценка от других пользователей, популярность
- Признаки взаимодействия — читал ли пользователь этого автора раньше, насколько книга похожа на прочитанные

### Ранжирование (Learning-to-Rank)
- Задача: не просто предсказать класс, а **упорядочить список** объектов по релевантности
- Модель выдаёт скоринг для пары (user, item), потом сортируем по убыванию
- **NDCG@K** — метрика качества; учитывает и позицию объекта в списке, и его релевантность
- LightGBM в режиме ranker — готовый инструмент для этой задачи

## 8. Обработка текстов (базовый уровень)

Нужен, когда в данных есть текстовые поля (описания, названия).

- **TF-IDF** — превращает текст в числовые признаки; `sklearn.feature_extraction.text.TfidfVectorizer`
- **Разреженные матрицы (sparse)** — TF-IDF даёт большие но почти пустые матрицы, бустинг умеет с ними работать
- Базовая очистка текста — нижний регистр, удаление пунктуации, стоп-слова

## 9. Docker (только для задач с инференсом)
