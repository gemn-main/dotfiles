```bash
chmod 644 file
```
644 - запись доступа в восьмиричной системе счисления 

0  ---
1   --x
2  -w-
3  -wx
4  r--
5  r-x 
6  rw-
7  rwx 


символьная фома записи
```bash
chmod u+x
```

u - сокращение от user, также есть g - группа, o - other и a - all (кому добавлять)

\+ или - означают добавление или снятие  

x, r, w - выволнение, чтение, запись

компоненты можно комбинировать: 
`ug+xrw`,  `go-x` и т.д.
