```python
soup = BeautifulSoup(src, 'lxml')
```

📌 `'lxml'` — это **парсер**.

BeautifulSoup может работать с разными парсерами:

| парсер      | скорость          |
| ----------- | ----------------- |
| html.parser | медленный         |
| lxml        | **очень быстрый** |
| html5lib    | очень точный      |
