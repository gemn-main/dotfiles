```python
x = np.linspace(0, 10, 100)
y = np.sin(x)

fig, axes = plt.subplots(2, 2, figsize= (10, 8))
axes[0,0].plot(x,y)
axes[0,0].set_title("line plot")

axes[0,1].scatter(np.random.rand(50), np.random.rand(50))
axes[0,1].set_title("scatter plot")


axes[1,0].bar(['A', 'B', 'C'], [3,7,5])
axes[1,0].set_title('bar chart')


axes[1,1].hist(np.random.randn(1000), bins=30)
axes[1,1].set_title('histogram')



plt.tight_layout()
plt.show()
```

- `plt.subplots(2, 2, ...)` — создаёт сетку 2x2, то есть 4 Axes. Возвращённый `axes` — это numpy-массив размером (2, 2), поэтому к каждому конкретному графику обращаемся как `axes[строка, столбец]`.
- `np.linspace(0, 10, 100)` — создаёт 100 равномерно распределённых точек между 0 и 10. Используется практически везде, где нужна ось X для непрерывной функции.
- `np.random.rand(50)` — 50 случайных чисел от 0 до 1 (равномерное распределение). Используется для scatter, где нужны случайные точки.
- `np.random.randn(1000)` — 1000 случайных чисел из нормального (гауссовского) распределения. Используется для histogram, чтобы показать форму "колокола".
- `plt.tight_layout()` — автоматически подгоняет отступы между subplot'ами, чтобы заголовки и подписи не наезжали друг на друга. Практически всегда стоит вызывать эту функцию перед `plt.show()`, если у тебя больше одного Axes.




| Тип графика   | Когда использовать                                          | Пример в ML/DS                                  |
| ------------- | ----------------------------------------------------------- | ----------------------------------------------- |
| **Line**      | Непрерывные данные, тренды, зависимость от времени или шага | Кривая обучения (loss по эпохам)                |
| **Scatter**   | Зависимость между двумя переменными, отдельные точки        | Визуализация embeddings, PCA, t-SNE             |
| **Bar**       | Сравнение дискретных категорий                              | Количество примеров по классам                  |
| **Histogram** | Распределение одной переменной                              | Распределение значений признака перед обучением |
