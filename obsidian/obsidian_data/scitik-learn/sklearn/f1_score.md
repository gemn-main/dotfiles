 ```python 
from sklearn.metrics import f1_score
f1 = f1_score(y_test, y_pred, average = 'macro')
```

- average='macro' — посчитать F1 для каждого класса отдельно, а затем взять простое среднее этих значений, не обращая внимания на то, сколько объектов в каждом классе.
 
- average='weighted' — то же самое, но с весом по размеру класса (крупные классы влияют на итог сильнее).

- average='micro' — посчитать TP/FP/FN сразу по всем классам вместе и уже потом вывести одну общую метрику.
