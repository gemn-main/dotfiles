```python
from sklearn.feature_extraction.text import TfidfVectorizer

texts = [
    "кот сидит на окне",
    "собака бежит по улице",
    "кот и собака играют",
]

vectorizer = TfidfVectorizer()
X_tfidf = vectorizer.fit_transform(texts)

print(X_tfidf.shape)               # (3, N) - 3 текста, N уникальных слов в словаре
print(vectorizer.get_feature_names_out())  # сам словарь
print(X_tfidf.toarray())           # числовая матрица (по умолчанию — разреженная, .toarray() для просмотра)
```

Если словарь — `[бежит, играют, и, кот, на, окне, по, сидит, собака, улице]` (10 уникальных слов), то первый текст превратится в вектор `[0, 0, 0, 1, 1, 1, 0, 1, 0, 0]` — единицы там, где слово встретилось, нули — где нет. Это и есть Bag of Words: у каждого текста получается один длинный числовой вектор, по одному числу на каждое слово из общего словаря.

### Что добавляет TF-IDF поверх этой идеи

Проблема простого счётчика слов: слова вроде "и", "на", "по" встречаются почти в любом тексте и почти ничего не говорят о его смысле, а более редкие и специфичные слова ("бежит", "играют") гораздо информативнее — но простой счётчик не делает между ними различия.

**TF-IDF** (Term Frequency — Inverse Document Frequency) — это способ взвесить каждое слово, а не просто посчитать. Название расшифровывается по двум частям:

- **TF (частота термина)** — как часто слово встречается **в этом конкретном тексте**. Чем чаще — тем выше вес (слово явно важно именно для этого текста).
- **IDF (обратная частота документа)** — насколько слово **редкое** во всём наборе текстов в целом. Если слово встречается почти в каждом тексте (как "и", "на") — его IDF будет маленьким (оно неинформативно, раз есть везде). Если слово редкое, специфичное — IDF будет большим.

Итоговый вес слова = `TF × IDF`. Слово получает высокий TF-IDF, если оно **часто встречается в конкретном тексте, но редко — во всех остальных**. Именно такие слова обычно и определяют смысл/тему текста.


```python
vectorizer = TfidfVectorizer(
    max_features=5000,     # оставить только 5000 самых частых слов - ограничивает размер словаря
    stop_words='english',  # выкинуть частые незначащие слова (для английского текста есть готовый список)
    ngram_range=(1, 2),    # учитывать не только отдельные слова, но и пары слов подряд ("не", "нравится" -> "не нравится")
)
```
