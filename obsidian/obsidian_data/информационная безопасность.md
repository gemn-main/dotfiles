### Уровень 1. Базовая защита Arch Linux (обязательно)

- Полное шифрование диска через LUKS.
- Надежный пароль пользователя и root.
- Отключить вход по паролю через SSH, использовать только ключи.
- Включить firewall:
    
    ```
    sudo pacman -S ufwsudo systemctl enable --now ufwsudo ufw default deny incomingsudo ufw default allow outgoingsudo ufw enable
    ```
    
- Установить AppArmor:
    
    ```
    sudo pacman -S apparmor
    ```
    
    Добавить в параметры ядра:
    
    ```
    lsm=landlock,lockdown,yama,integrity,apparmor,bpf
    ```
    
- Регулярно обновлять систему:
    
    ```
    sudo pacman -Syu
    ```

### Уровень 2. Усиление ядра

Установить hardened-ядро:

```
sudo pacman -S linux-hardened linux-hardened-headers
```

Дополнительно:

```
sudo pacman -S sysctlconf
```

Добавить в `/etc/sysctl.d/99-security.conf`:

```
kernel.kptr_restrict=2kernel.dmesg_restrict=1kernel.unprivileged_bpf_disabled=1kernel.yama.ptrace_scope=2net.ipv4.conf.all.rp_filter=1net.ipv4.icmp_echo_ignore_broadcasts=1
```

Применить:

```
sudo sysctl --system
```

### Уровень 3. Изоляция приложений

sudo pacman -S firejailfirejail firefox

### Уровень 4. Анонимность сети

Для обычного серфинга:

- VPN без логов.
- DNS через DoH или DoT.
- Блокировка WebRTC.

Для серьезной анонимности:

- Только Tor Browser.
- Не логиниться в личные аккаунты.
- Не использовать привычные расширения.
- Не менять настройки Tor Browser.

Даже если использовать Tor, вход в свой Google-аккаунт уничтожает большую часть анонимности.

---

### Уровень 5. Защита от отслеживания браузером

Использовать:

- Tor Browser — для анонимности.
- Firefox с настройками privacy — для обычной работы.

В Firefox:

```
about:config
```

Изменить:

```
privacy.resistFingerprinting = truemedia.peerconnection.enabled = falsegeo.enabled = false
```

Установить расширения:

- uBlock Origin
- CanvasBlocker
- Cookie AutoDelete

### Уровень 6. Виртуализация

Если ты действительно готов потратить много времени, то самый сильный шаг — разделить деятельность по виртуальным машинам.

Установить:

- QEMU
- KVM
- virt-manager

Схема:

- Хост: Arch Linux + Hyprland.
- VM №1: работа.
- VM №2: эксперименты.
- VM №3: анонимность через Tor.
- VM №4: подозрительные файлы.
