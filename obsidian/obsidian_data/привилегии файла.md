```bash
[user@gemn ~]$ ls -l file
-rw-r--r-- 1 user user 0 Aug 13 16:34 file
[user@gemn ~]$ 
```


первый символ означает тип файла:
\-  просто файл 
d - каталог 
l - ссылка

дальше привилегии по 3 символа 
владелец      групп       мир 
rwx                 rwx          rwx 

r -  открывать и читать
w - запись файла 
x  - запускать файл как программу
